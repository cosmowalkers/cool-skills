# 旧 docs 迁移指南

迁移前先把旧文件拆成知识单元，再逐条分类。不要按旧文件名机械搬迁。

| 旧内容 | 新归属 |
|---|---|
| 架构取舍和技术选型原因 | `decisions/` |
| i18n、子模块边界、性能硬约束 | `rules/` |
| CDN、构建变量、业务语义速查 | `reference/` |
| 本地开发、部署和验证步骤 | `guide/` |
| 历史问题和兼容性陷阱 | `gotchas/` |
| 路由表、接口清单、组件 props | 丢弃，不迁移 |

迁移结果必须记录：

- 原文件；
- 新文件；
- 被删除或不迁移的内容；
- 证据来源；
- 共享页 / 仓库页 / 子仓页归属；
- 需要人工确认的事实。

原文件暂时保留时，在原文件顶部追加指向新页面的迁移说明；确认迁移完成后再删除或
缩减原文件，避免出现两个活跃事实来源。
