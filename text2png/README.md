# text2png｜把文字变成好看的图表

把一段文字丢给 AI，直接得到一张**设计好的图表 PNG**，可以贴进文档、周报、汇报 PPT、分享材料。
不需要会设计，也不需要画图工具——描述清楚内容，选个形式（或让 AI 帮你选），几十秒出图。

支持 **15 种图表形式 × 9 种视觉主题 = 135 种组合**，形式和主题可以自由搭配。

## 一、能画什么

**图表形式**决定版式（长什么样），选一个最贴近内容的即可：

| 形式 | 适合的内容 |
| --- | --- |
| 时序图 | 谁先谁后、一来一回的交互：调用链、消息往来、操作与响应的先后顺序 |
| 泳道图 | 多方协作的流程：每个角色/部门在哪些环节做什么（如需求、审批、上线流程） |
| 流程图 | 有步骤和分支的流程：判断、成功/失败两条路怎么走 |
| 对比表 | 多个对象的多维度比较：方案选型、版本差异、竞品功能对照 |
| 时间线 | 按时间展开的事件：里程碑、发展历程、项目关键节点 |
| 架构拓扑 | 系统由哪些部分构成、如何分层与依赖（如服务架构、部署结构） |
| 数据看板 | 一组核心指标的集中展示：KPI、运营数据、监控概览 |
| 甘特图 | 排期与工期：任务什么时候开始、持续多久、哪些在并行 |
| 组织架构 | 层级与归属：团队结构、汇报关系、权限分层 |
| 漏斗图 | 逐级减少的过程：转化路径、各环节流失（浏览 → 加购 → 下单） |
| 思维导图 | 一个主题层层展开：知识体系、方案拆解、发散思路 |
| 矩阵图 | 两个维度上做判断：优先级、成本收益、风险分级 |
| 看板 | 按状态分列：待处理 / 进行中 / 已完成，适合任务和进度总览 |
| 清单卡 | 要点的整齐罗列：检查项、验收标准、注意事项、发布清单 |
| 金句卡 | 一句话或一段结论的视觉卡片：每日一句、核心观点、活动口号 |

**视觉主题**决定外观（配色、字体、质感），只影响好不好看，不影响内容：

| 主题 | 观感与适用场景 |
| --- | --- |
| warm（默认） | 暖色米白底、彩色边框，通用性最好，报告和流程都合适 |
| dark | 深色高对比科技感，适合架构、技术方案 |
| minimal | 极简黑白，克制干净，适合正式汇报 |
| editorial | 杂志排版、大号衬线字体，适合内容展示和品牌调性 |
| neon | 赛博霓虹荧光色，适合技术分享、演讲配图 |
| paper | 手绘纸张质感，适合教学、说明类内容 |
| glass | 半透明玻璃拟态，适合产品介绍、发布会物料 |
| corporate | 深蓝商务主色，适合客户方案、正式汇报 |
| retro | 复古像素 + 扫描线，适合技术社区、趣味内容 |

## 二、怎么用

在 Claude Code / Codex 里用一句自然语言描述即可，例如：

- 「帮我画一张下单流程的时序图」
- 「把这三套方案的差异做成对比表」
- 「这个季度的核心指标做个数据看板，用深色风格」
- 「把这次活动规则做成一页金句卡」
- 「把用户运营的协作流程画成泳道图」

把原始材料直接贴进去就行：会议纪要、需求描述、表格、SOP 文字都可以。不确定用哪种形式或主题，就加一句「你帮我挑」，AI 会按内容自动选。

想指定的话，形式名和主题名可以直接写在描述里（如「时序图 + glass」）。生成结果是一张高清 PNG（默认 4 倍清晰度，可再缩放使用），保存在你指定的目录。

## 三、怎么看 demo

Skill 自带一份**全矩阵演示页**，135 种组合一次看全。不用管文件放在哪，直接跟 AI 说一句，它会帮你打开：

- 「打开 text2png 的 demo」
- 「打开画图的 demo」

页面在浏览器里直接操作，不需要装任何东西，也不依赖网络：

1. **筛选**：顶部按钮可按「形式」或「主题」过滤，快速看同一内容在不同风格下的效果
2. **放大**：点任意一张图进入大图预览，支持适应屏幕 / 1:1 / 200% / 300%，`←` `→` 翻页，`Esc` 关闭
3. **复制 prompt**：每张卡片和预览顶栏都有「复制 prompt」，点一下得到一行提示词，形如 `画成时序图（sequence），主题用 warm（暖色报告）：<把内容写在这里>`，把尖括号占位符换成你的内容，整行发给 AI 就能出同款

挑好形式与主题 → 复制 prompt → 替换内容 → 发给 AI，这是最快的上手路径。

## 四、首次使用准备

只有生成图片的脚本需要准备一次环境（看 demo 不需要）：

1. 机器上装有 Google Chrome（脚本会自动查找）
2. 在 skill 目录执行一次 `npm install`（安装 `puppeteer-core`）

之后正常使用无需再管。若在内网离线环境，外链字体无法加载，排版会自动回退，图表仍能正常生成。
